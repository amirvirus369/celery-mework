# پیاده سازی بخشی از یک پروژه با سلری  

در پروژه اصلی برای ایجاد اگهی و ساخت رزومه 
به دلیل چند زبان بودن سایت 
باید برای دو زبان ترجمه اتفاق بیفته 
سر همین داستان کاربر زیاد معطل میشه 



#  درباره این پروژه 

با سلری دقیقا قسمت هایی از پروژه که کاربر معطل میشه رو پیاده سازی کردم
تا قدرت سلری رو با هم ببینیم 



# تکنولوژی های استفاده شده 

- Django

- celery

- redis

- psycopg2-binary

- django-parler

- deep_translator

- packaging

- Pillow



# روش ران کردن این پروژه 

اول از همه باید داکر رو نصب داشه باشید 
داکر وقتی به حالت استارت قرار گرفت 
ادامه داستان رو پیش برید 


این دستور رو بزنید برای اینکه پروژه ران و تمام نیازمندی هاش انجام بشه 

```bash
docker compose up -d --build

```

با ادرس لوکال هاست و پورت 8000 در دسترس قرار میگیره 
اگر در مرحله بیلد به ارور نخوره 

```bash
127.0.0.1:8000

```
